### Term 3

#### Unsupervised Learning
**Course code:** MATH70102

- Dimensionality reduction: principal component analysis (PCA), extensions of PCA (sparse and kernel), canonical correlation analysis, non-negative matrix factorisation, independent component analysis, multidimensional scaling, non-linear dimensionality reduction.
- Density estimation: parametric density estimation, estimation of mixtures using the EM algorithm, non-parametric density estimation (kernel and histogram).
- Clustering: K-means clustering, K-medoids clustering, hierarchical clustering, evaluation measures.
- Anomaly and outlier detection: local outlier factor, one-class support vector machine.


#### Bayesian Methods and Computation
**Course code:** 70100

- Uncertainty and Decisions
- Prior and Likelihood Representation
- Graphical Modelling and Hierarchical Models
- Parametric Models & Monte Carlo
- Computational Inference
- Analytic Approximations & Bayesian Software Packages
- Criticism & Model choice
- Linear Models
- Non-parametric Models
