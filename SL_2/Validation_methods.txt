Validation Strategy and Procedures
Validation strategies are used for model selection (choosing flexibility/hyperparameters) and model assessment (estimating generalization error).
Data Partitioning:
Training/Validation/Test Split: Partitioning data (e.g., 60% training, 20% validation, 20% test) to avoid the optimism of training error.
train_test_split(): The standard function for creating these disjoint sets.
Cross-Validation (CV) Procedures:
k-Fold Cross-Validation: Dividing data into k groups (folds) and iteratively training on k−1 and testing on the remaining one. Implemented via KFold() or cross_val_score(cv=k).
Leave-One-Out (LOOCV): A special case where k=n. It is approximately unbiased but can have high variance and high computational cost (unless using the efficient formula for linear models).
Stratified CV: Ensuring class proportions are preserved in each fold, essential for imbalanced classification.
The Bootstrap (Quantifying Uncertainty):
Non-parametric Bootstrap: Repeatedly drawing samples of size n with replacement from the data to estimate the sampling distribution of any statistic or parameter.
Leave-one-out Bootstrap (OOB): Evaluating performance on observations not included in a specific bootstrap sample (Out-of-Bag) to estimate generalization error.
boot_SE(): Custom function strategy used to compute bootstrap standard errors.
Hyperparameter Tuning and Model Selection:
Grid Search (GridSearchCV): Exhaustively searching a parameter grid (e.g., k in kNN, C in Logistic Regression, α in Lasso) using cross-validation.
One-Standard-Error Rule: A heuristic choosing the simplest model whose error is within one standard error of the minimum CV error to prevent overfitting.
Information Criteria: Analytical alternatives to resampling, including AIC, BIC, C_p, and Adjusted R^2.
Performance Metrics:
Regression: Mean Squared Error (MSE) and R^2.
Classification: Accuracy, Error Rate, Log-loss (for probability calibration), and ROC-AUC.
Confusion Matrices: Using ConfusionMatrixDisplay to visualize classification errors.
