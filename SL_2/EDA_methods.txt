Exploratory Data Analysis (EDA) Methods
EDA is focused on understanding the signal and identifying issues like nonlinearity, skewness, and the "curse of dimensionality".
Variable Identification and Summaries:
Categorization: Classifying variables into qualitative (categorical, binary, ordinal) and quantitative (discrete, continuous).
Numerical Descriptions: Using df.describe() for quantitative statistics (mean, std, percentiles) and value_counts() or unique() to inspect categorical levels.
Skewness Analysis: Calculating numerical skew values (e.g., train[col].skew()) to identify right-skewed variables requiring log-transformation.
Visualizing Distributions:
Histograms: Using sns.histplot() or .hist() to visualize the spread of predictors.
Boxplots: Using .boxplot() to identify outliers and compare variable spread across classes.
Violin Plots: Using kernel density estimates to distinguish distribution shapes more effectively than boxplots.
Relationship and Structure Mapping:
Scatterplot Matrices (Pair Plots): Using sns.pairplot() or pd.plotting.scatter_matrix() to visualize all pairwise relationships and marginal densities simultaneously.
Correlation Matrices: Using df.corr() often visualized with sns.heatmap() to detect multicollinearity or strong predictors.
CCPR Plots: Component-Component plus Residual plots to assess specific nonlinear relationships between a predictor and the target.
Unsupervised EDA for High Dimensions:
Principal Components Analysis (PCA): Reducing high-dimensional data (e.g., 40+ genes or one-hot encoded categories) into 2D or 3D for visualization.
Biplots: Manually or automatically creating plots that display both principal component scores (observations) and loading vectors (variable directions).
Scree Plots: Visualizing the Proportion of Variance Explained (PVE) by each component to identify the "elbow" or optimal number of dimensions.
